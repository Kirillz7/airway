# AIRWAY — симулятор первой помощи

Учебный проект по дисциплине «Безопасность жизнедеятельности» (РЭУ им. Г.В. Плеханова).
Тема: первая помощь при непроходимости дыхательных путей.

## Запуск
1. Скачать папку `airway-simulator`.
2. Двойной клик по `index.html`.
Всё работает локально, без сервера и интернета.

## Структура
- `css/` — стили по модулям (база, компоненты, экраны, анимации, печать)
- `js/utils/` — DOM-хелперы и localStorage
- `js/data/` — сценарии (5 кейсов) и библиотека алгоритмов
- `js/core/` — состояние, таймер, роутер
- `js/ui/` — компоненты, фидбек, дебриф, экраны
- `js/app.js` — bootstrap

## Как добавить кейс
Открыть `js/data/cases.js`, добавить объект в массив `App.CASES` по образцу. Код трогать не нужно.

## QR-карты
Ссылки вида `index.html#briefing/adult`, `#briefing/infant`, `#briefing/pregnant` и т.д.
Сгенерировать QR можно в любом бесплатном генераторе (например, qr-code-generator.com).

## Миграция на ES-модули (опционально)
Заменить в каждом файле `(function (App) { … })(window.App = …)` на `export …`,
в `index.html` — `<script type="module" src="js/app.js">`. Запускать через Live Server.

## Источники
ERC Guidelines 2021, AHA Guidelines 2020.

## Дисклеймер
Образовательный проект. Не заменяет курс первой помощи и консультацию врача.
